# ALTURA Typography System

## Direction
ALTURA uses a restrained neo-grotesque system inspired by premium editorial running and fashion commerce.

## Font stack
`Inter`, `Helvetica Neue`, `Helvetica`, `Arial Nova`, `Arial`, `sans-serif`

Inter is the primary free webfont. The production site loads it from Google Fonts. The fallbacks keep the store usable if the font CDN is unavailable.

## Core rules
- Display headings: weight 400, approximately -0.03em tracking, compact but readable line-height.
- UI navigation: weight 450, small sizing, restrained positive tracking.
- Labels: uppercase, approximately 0.05–0.07em tracking.
- Body copy: weight 400, 1.55–1.60 line-height, very little tracking.
- Product names: regular weight; never bold by default.
- Prices: regular weight with tabular numerals.
- Wordmark: medium weight with intentionally wide tracking; it is treated separately from site typography.

## Important
PP Neue Montreal is not bundled in this project. If ALTURA later licenses that family for commercial web use, the design tokens are structured so the primary font can be swapped without redesigning the layout.
